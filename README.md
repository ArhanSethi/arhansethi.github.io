# Arhan Sethi portfolio

Static portfolio ready for GitHub Pages. No build step or package installation is needed.

## Publish

1. Create a public GitHub repository named YOUR-USERNAME.github.io, replacing YOUR-USERNAME with your exact GitHub username. If this repository already exists, use it without deleting unrelated files.
2. Extract this ZIP on your computer. Upload its contents to the repository root, so index.html is directly in the root (not inside an extra folder). Include the downloads folder and orderbook-data.json.
3. Open Settings > Pages. Under Build and deployment, select Deploy from a branch, then main and / (root). Save.
4. Wait for deployment to finish. Your site will be at https://YOUR-USERNAME.github.io/.

This site also works from a project repository because its asset paths are relative.

## Files

- index.html: layout and copy
- style.css: styling
- app.js: project overlays and interactive demos
- orderbook-data.json: synthetic replay snapshots
- downloads/: the four supplied project ZIPs

The project ZIPs are copied exactly from the current portfolio downloads.
